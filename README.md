# SQE Showcase v1.0

Mobile-first, static Supplier Quality Engineering showcase. Includes Overview, SPC Monitoring, Supplier Performance, Material 360°, Tooling Gallery, and About.

All figures and suppliers are fictional. No internal network connections, company data, or secrets.

Deploy on Vercel as an **Other** framework, root directory `/`, with no build command. The static `index.html` is the entry point.
